# Mine Services — KPI

## Status

Planned.

## KPI Domains

Initial candidates include:

- Production / operational achievement
- Equipment availability
- Equipment utilization
- Effective utilization
- MTBF
- MTTR
- Fuel-related indicators where source data supports them
- Road and infrastructure service performance
- Drainage/dewatering performance

## Contract

KPI values are derived outputs.

```text
Source Records
      ↓
Validation
      ↓
KPI Calculation
      ↓
KPI Result
      ↓
Report / Dashboard
```

A dashboard number without a traceable source record is not considered authoritative.
